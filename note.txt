# Cấu trúc backend — giữ nguyên tên file gốc mà team đã đặt, chỉ gom theo module
backend/
├── main.py          # 1 entrypoint duy nhất — chỉ include router ở đây, không viết logic
├── core/             # config.py, database.py (Mongo/Firebase dùng chung), logging.py
└── modules/
    ├── auth/          # register.py, login.py, profile.py — mỗi file tự chứa router + schema,
    │                  #   gọi thẳng core.database.get_auth_db(). Không tách service/repository.
    ├── ocr/           # ocr.py (router + upload/background job, như api/v1/ocr.py cũ)
    │                  #   pipeline.py, formula_detector.py, formula_processor.py, text_cleaner.py,
    │                  #   easyocr_engine.py, schemas.py, mongodb.py — đúng tên cũ trong services/ocr, engine, models
    ├── rag/           # chunking.py (router /api/v1/chunk + thuật toán chunk, gộp từ api/v1/chunking.py
    │                  #   + services/rag/chunking.py vì trùng tên gốc)
    │                  #   search.py, chromadb_engine.py, chunking_export.py, schemas.py, mongodb.py
    ├── generation/    # generate.py (router, từ api/v1/generate.py), question.py (logic sinh câu hỏi,
    │                  #   từ services/generation/question.py), prompt_builder.py, prompt_loader.py,
    │                  #   llm/{base,factory,gemini,qwen,deepseek}.py, schemas.py, mongodb.py
    └── dictionary/    # dictionary.py (auto-learning, từ services/rag/dictionary.py), mongodb.py
                       #   (không có router riêng — chạy nền, được rag/chunking.py gọi)

# Quy ước khi thêm code mới:
# - Trong 1 module, cứ đặt tên file theo đúng vai trò cũ (vd thêm truy vấn Mongo mới -> mongodb.py,
#   thêm endpoint mới -> file router của module đó). Nếu 2 file gốc trùng tên (vd router và service
#   cùng tên "chunking.py" ở 2 thư mục khác nhau) thì gộp lại 1 file duy nhất thay vì đặt tên khác đi.
# - Router CHỈ nhận request/trả response; nếu cần tách riêng logic phức tạp thì thêm hàm ngay trong
#   cùng file (như ocr.py, chunking.py) thay vì tạo thêm service.py/repository.py mới không có tiền lệ.
# - Thêm module hoàn toàn mới -> tạo modules/<ten_module>/, đặt tên file theo nội dung file đó làm gì
#   (không bắt buộc router.py/service.py/repository.py).
# - Router mới CHỈ được include trong backend/main.py (app.include_router), không tạo FastAPI() ở nơi khác.
